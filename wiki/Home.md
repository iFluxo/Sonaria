# Welcome to the Sonaria Wiki

Sonaria is a powerful and easy-to-use music library for Discord bots built on
[Seyfert](https://seyfert.dev). It manages queues, playback and voice connections, ships a native
Discord voice implementation, and sources music through a plugin architecture.

This wiki provides comprehensive guides and documentation to help you build the best music bot.
